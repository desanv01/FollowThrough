# FollowThrough shared working rules

Before any Codex or DeepSeek task, read [the required task policy](docs/project/DEADLINE-MODE.md) and the current [master checklist](docs/project/MASTER-CHECKLIST.md).

**Full scope; minimal verification.** Complete every approved phase, subphase, task and subtask. Use minimal meaningful tests and brief reviews. Fix blockers, document and defer nonblocking bugs/deep hardening, then move forward once the required behavior works. Do not drop deliverables without explicit user instruction or label unverified behavior as verified.

Main includes this instruction in every new worker prompt and review assignment. The full policy is maintained in `docs/project/DEADLINE-MODE.md`; this file is its root entry point. Read `.coordination/CONTROL.md` and the finite packet for current ownership and scope.
