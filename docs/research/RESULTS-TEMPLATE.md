## 8. Fill procedure (from accepted evidence only)

1. Confirm the freeze manifest and dataset identity; reject mixed `evidence_kind`/`stage` rows.
2. Generate the report from the accepted reporting revision and sanitized projection; record the
   revision and command in the reproduction record.
3. Transcribe counts from `report.json`; do not recompute by hand except as a deliberate independent
   spot check.
4. Verify each `strict_outcome` against the rule: eligible non-completed rows fail; for completed
   rows, fail if any component fails, otherwise unknown if any component is unknown, otherwise pass.
5. Verify `attempted = eligible + excluded`, denominator = eligible, and preserve unknown counts.
6. Keep every failed attempt and every exclusion; never delete an unfavourable row or rerun to
   replace it.
7. State limitations L1–L10 with the result; no model ranking, no unsupported significance test and
   no causal claim about JSON or structured progress.
